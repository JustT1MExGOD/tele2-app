## Изменение решения

Перед изменением прочитайте контекст и связанные материалы. Существенный пересмотр оформляйте новым ADR или явно датированным уточнением, сохраняя историю причин. Общая карта системы находится в [архитектуре](../ARCHITECTURE.md).
