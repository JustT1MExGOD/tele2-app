## Версии компонентов

Пакеты версионируются независимо по схеме `MAJOR.MINOR.PATCH`: эпоха, функциональное изменение, исправление. Версию меняют у затронутого пакета. Изначальная идея общего номера для всех компонентов заменена независимыми выпусками.

| Компонент | Версия в исходном архиве | Источник |
| --- | --- | --- |
| Сервер и веб-интерфейс | `20.57.5` | `backend/package.json` |
| Приложение Windows | `20.56.7` | `desktop/package.json` |
| Relay | `20.56.1` | `relay/package.json` |

`app.getVersion()` и `t2Desktop.getVersion()` показывают версию установленного desktop. Таблица описывает исходники, а не состояние публичных серверов.

## Подготовка и сборка

Выполняйте команды из корня репозитория на Windows с поддерживаемой проектом версией Node.js:

```powershell
cd desktop
npm ci
npm run desktop:typecheck
npm test
npm run desktop:package
```

Сборка запускает TypeScript, объединяет preload через `scripts/bundle-preload.mjs`, затем вызывает `electron-builder --win --x64`. Единый файл preload необходим для песочницы Electron: она не поддерживает обычную загрузку произвольного многофайлового результата через `require()`.

Результат: `desktop/release/T2Sales-Setup-x64-<version>.exe` и сопутствующий `.blockmap`. NSIS устанавливает приложение для текущего пользователя без обязательных прав администратора. Параметры находятся в `desktop/electron-builder.yml`.

Из каталога `desktop` вычислите контрольную сумму конкретной сборки:

```powershell
Get-FileHash .\release\T2Sales-Setup-x64-20.56.7.exe -Algorithm SHA256
Get-AuthenticodeSignature .\release\T2Sales-Setup-x64-20.56.7.exe
```

Имя в примере соответствует версии исходников. При следующем выпуске используйте фактическое имя файла.

## Подпись установщика

В исходной конфигурации нет настроенного сертификата Authenticode. Для подписания нужен настоящий сертификат; секреты `CSC_LINK` и `CSC_KEY_PASSWORD` передают через защищённые настройки сборки. Закрытый ключ не добавляют в репозиторий.

Текущая политика клиента для `stable` и `beta` — `warn`: отсутствие подписи допускается с предупреждением. Недействительная подпись, недоверенная цепочка и ошибка проверки блокируют установку. Это текущее поведение кода; целевая практика выпуска — подписывать распространяемые установщики. Предупреждения Windows нельзя устранять отключением системных проверок.

## Обновления и публикация

Используется собственный механизм из `desktop/src/main/updater/`, отдельный от `electron-builder autoUpdater`. Он обращается к `https://updates.vincere-mortem.ru` напрямую. Загрузка и установка требуют действий пользователя.

Порядок публикации, схема манифеста и проверка SHA-256 описаны в [руководстве по обновлениям](DESKTOP-UPDATES.md). Сначала публикуют и проверяют установщик, затем атомарно заменяют манифест канала.

> **Историческое подтверждение.** В предыдущих материалах зафиксировано успешное обновление `20.56.4 → 20.56.5` на проблемном ПК. Оно не подтверждает автоматически установку `20.56.7`, доступность сервера сейчас или готовность серверного чата.

## Relay и настройки установленного приложения

В исходниках указан relay `https://relay.vincere-mortem.ru` с upstream `https://tele2-app-production.up.railway.app`. Эти адреса описывают конфигурацию, а не результат текущей проверки доступности.

Упакованная версия использует стандартный relay при отсутствии непустого `T2_RELAY_URL`. Для явного отключения переключения задайте `T2_NETWORK_MODE=direct_only`. Пустое значение адреса не является надёжным способом отключения: применяется значение по умолчанию. См. [сетевое руководство](DESKTOP-NETWORK.md).

## Возврат после неудачного выпуска

1. Остановите продвижение проблемного установщика: замените манифест проверенным вариантом.
2. Учитывайте, что клиент игнорирует версии ниже или равные установленной. Старый манифест не откатывает обновившихся пользователей.
3. Для них подготовьте исправляющий выпуск с большим номером `PATCH` либо согласованную ручную переустановку.
4. Relay откатывайте независимо. Его отключение убирает резервный маршрут; прямое соединение доступно там, где работает сеть.
5. Проверьте запуск, авторизацию, сохранность пользовательских данных и обновление на Windows.

Удаление приложения не следует описывать как гарантированную очистку всех пользовательских данных: это зависит от поведения установщика и выбранной процедуры. Системный прокси и VPN приложение по своей архитектуре не устанавливает.
