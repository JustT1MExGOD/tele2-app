# sql/

Исторические ручные SQL-снимки и разовые запросы, накопленные по ходу
разработки — **не источник схемы**. Реальная схема БД живёт только в
пронумерованных миграциях `backend/migrations/`, применяются они
автоматически при старте сервера (`runMigrations()`, `src/index.ts`).

См. `docs/DEVELOPMENT.md` для того, как менять схему на практике.
