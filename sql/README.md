# Исторические SQL-материалы

[Документация](../docs/README.md) · [Обзор проекта](../README.md)

В каталоге `sql/` находятся ручные снимки и разовые запросы прошлых этапов разработки. Они помогают разобраться в истории, но не определяют актуальную схему базы.

## Где находится действующая схема

Источник изменений — пронумерованные файлы в [`backend/migrations/`](../backend/migrations/). При запуске сервера `runMigrations()` применяет ожидающие миграции. Порядок и уже применённые изменения учитывает штатный механизм проекта.

## Как использовать материалы

1. Сначала проверьте актуальные миграции и репозитории данных.
2. Если старый запрос полезен, адаптируйте его к текущей схеме и оформите изменение штатным способом.
3. Проверьте его на одноразовой локальной базе.
4. Не выполняйте исторический файл напрямую в рабочей БД как инструкцию установки.

Изменение схемы оформляется новой миграцией; старые применённые миграции не переписываются ради отката. Действующие процедуры: [разработка](../docs/DEVELOPMENT.md), [эксплуатация](../docs/RUNBOOK.md), [правила разрешённых действий](../CLAUDE.md).
