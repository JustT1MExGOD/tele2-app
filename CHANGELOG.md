# История изменений T2 Sales

[Документация](docs/README.md) · [Обзор проекта](README.md)

История разделена по эпохам: каждая версия имеет собственный раздел, поэтому записи можно читать и находить по оглавлению, без таблиц на сотни строк. Дополнительные записи из старого README сохранены отдельно внутри соответствующей эпохи.

> **Версии исходного архива:** backend `20.57.5`, desktop `20.56.7`, relay `20.56.1`. Номер в исходниках не подтверждает публикацию или развёртывание.

## 20.57.5 — функциональные исправления и оптимизация (RC, не развёрнут)

- Общая транзакция продажи, ключа повтора, журналов и XP; десятичная арифметика PostgreSQL.
- Единый дневной план на выбранную дату, снимок при открытии смены, повторяемое закрытие.
- Исправления BFQ/CSV/кассы/пользовательских метрик, пакетные сводки и переносы графика.
- Сохраняемые задания отчётов, восстановление SVG-воркеров, ограниченные очереди.
- REST-дочитывание чата, LISTEN/NOTIFY между репликами, ограничение ленты и потоковый CSV.
- Состояние офлайн-очереди в интерфейсе, сокращённые шрифты.
- Исправление desktop, первоначально описанное для 20.56.6: устаревший сетевой probe не меняет новый режим.
- Подробности, проверки и оставшиеся рекомендации: [отчёт об исправлениях](IMPLEMENTATION-20.57.5.md).

## Как читать записи

Номер версии относится к компоненту и проходу, указанным в записи. Формулировки «проверено», «выпущено» и числа тестов являются историческими заявлениями соответствующего отчёта. Текущие команды находятся в [руководстве разработчика](docs/DEVELOPMENT.md), а правила изменения версии — в [рабочем соглашении](CLAUDE.md).
