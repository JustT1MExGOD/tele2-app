# История версий нативного приложения

[Каталог документации](../docs/README.md) · [Нативное приложение](README.md)

Версии нативного клиента ведутся отдельно от веба и backend. Здесь — что менялось в каждой версии. Общая история проекта — в [CHANGELOG.md](../CHANGELOG.md) в корне репозитория.

## 1.1.0

Запуск в стиле Discord, палитра команд, живой Heatmap, новые выпадающие списки и анимации по всему интерфейсу.

**Добавлено**

- **Сплэш при запуске.** Небольшое прозрачное окно проверяет соединение, ищет обновление, при наличии скачивает и ставит его, проверяет сессию; затем клиент плавно открывается. Ошибка обновления запуск не блокирует. Код: `ui/boot/`.
- **Обновление при запуске без клика.** Установщик получил ключ `/UPDATE`: без приветствия, сразу установка, затем сам запускает новую версию. Проверки безопасности (только https, точный origin, без редиректов, SHA-256, размер, подпись по политике, повторная проверка перед запуском) прежние.
- **Палитра команд Ctrl+K.** Поиск по экранам, инструментам и действиям; для менеджеров и администраторов — «Продажа: ФИО». Ctrl+N — «Добавить продажу».
- **Живой Heatmap.** Каскад, плавное перетекание значений, самообновление раз в 30 с, деталь часа при наведении, пульсация лучшего часа, отметка текущего часа.
- **Анимации интерфейса.** Общий словарь движения `Motion.kt`: переход между экранами, каскад блоков, отсчёт чисел, заполнение полосок прогресса, скелетоны вместо спиннера, отклик кнопок и бокового меню.
- **Единые выпадающие списки** (`DropdownField`, `PopoverPanel`) вместо стандартного меню Material: по ширине поля, со скруглением, тенью и галочкой на текущем значении.

**Изменено**

- Политика обновления: при запуске новая версия ставится сразу (раньше — только по кнопке). Обновление, найденное во время работы, по-прежнему предлагается карточкой.
- `AppRoot` больше не проверяет сессию и не запускает сеть: это делает сплэш.
- Панель состояния сети оформлена как карточка у индикатора.

**Исправлено**

- Строка «лучший час» в Heatmap переносилась криво в узком окне; часы с отрицательными значениями выглядели пустыми.
- Окно клиента после сплэша выводится на передний план, а не остаётся позади других окон.

**Проверено и не проверено** — см. [FEATURES.md](docs/FEATURES.md#что-проверено). Реальное обновление с сервера на новую версию целиком в живой среде не прогонялось.

## 1.0.0

Первая версия, полный перенос веб-приложения.

- Перенесены все экраны веб-версии: главная, профиль, задачи, график с черновиками, команда, чат по WebSocket, Command Center, касса, план дня и месячные планы, отчёты и отчёт-картинка, Heatmap, прогноз, алерты, объявления, поддержка, история продаж, BFQ, супервайзер, администрирование и Admin Center. Список и код — [FEATURES.md](docs/FEATURES.md).
- Диалоги: добавление продажи, открытие и закрытие смены, замена, метрики сотрудника, калькуляторы и промокоды.
- Сеть DIRECT и RELAY с автопереключением, диагностикой и ручным выбором режима (порт Electron).
- Обновления: манифест на отдельном сервере, загрузка с проверкой SHA-256 и размера, политика подписи, повторная проверка перед запуском, журнал.
- Установщик на пользователя в стиле экрана входа: анимации, живые фразы, установка без прав администратора, обновление поверх, удаление.
- Значок приложения из логотипа T2.
