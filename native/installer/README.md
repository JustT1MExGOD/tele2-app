# Установщик T2 Sales Native

[Каталог документации](../../docs/README.md) · [Нативное приложение](../README.md)

Один файл `T2SalesNative-Setup-x64-<версия>.exe`. Собирается `./gradlew :desktopApp:packageSetup` (см. `desktopApp/build.gradle.kts`).

## Устройство

```
[ заглушка (WPF, ~280 КБ) ][ payload.zip = образ приложения от jpackage ][ метаданные ][ хвост 32 байта ]
```

* **Заглушка** (`setup/*.cs`) — небольшая программа на WPF. Компилируется штатным компилятором Windows (`csc.exe` из .NET Framework 4.x, язык C# 5), ничего ставить не нужно. Открывается мгновенно, без второй JVM, и распаковывает архив уже под красивым окном с настоящим прогрессом.
* **Хвост** = `T2SETUP1` + смещение архива + длина архива + длина метаданных (три `int64`, little-endian). По нему заглушка находит архив внутри собственного файла.
* **Uninstall.exe** — копия одной заглушки (первые *смещение* байт установщика) без архива. Нет хвоста — значит, запуск в режиме удаления. Запускается только из папки, где лежит `T2 Sales Native.exe`, иначе отказывается (чтобы случайный запуск голой заглушки ничего не удалил).

## Режимы запуска

| Запуск | Что делает |
| --- | --- |
| `Setup.exe` | Окно установки или обновления (если уже установлено) |
| `Setup.exe /S` | Тихая установка, без окна, код возврата 0/1 |
| `Setup.exe /UPDATE` | Обновление, запущенное самим приложением: без страницы приветствия, установка сразу, затем новая версия запускается сама и окно закрывается (только для установки; проверить вид: `/demo /demo-update /UPDATE`) |
| `Uninstall.exe` / `Uninstall.exe /S` | Окно удаления / тихое удаление |
| `... /demo`, `/demo-update`, `/demo-uninstall` | Просмотр окна с поддельным движком, ничего на диске не трогает (для работы над дизайном) |

## Дизайн

Копия экрана входа приложения (`ui/login/LoginScreen.kt`): тёмный градиент `#0E2230 → чёрный`, арбуз и «T2 Sales», стеклянная карточка радиусом 24 с тонкой рамкой, светлая основная кнопка. Палитра — из `shared/theme/T2Tokens.kt` (тёмная тема), см. `setup/Theme.cs`.

Анимации: появление блоков со сдвигом и затуханием, пульсирующее свечение и «парение» арбуза, страница установки с графиком «Факт / План / Прогноз» (столбики продаж растут по одному, линия факта рисуется вместе с прогрессом, пунктир плана, зелёный точечный прогноз, пульсирующая точка), плавный индикатор с бликом, смена подписей («Считываем графики смен…», «Делаем прогнозы выполнения планов…» и т. д.) и финал с рисующейся галочкой и конфетти. Подписи привязаны к процентам и чисто декоративные, реальная работа — распаковка файлов.

Индикатор не бежит быстрее, чем за ~7 секунд (удаление ~4): анимацию нужно успеть увидеть, даже когда распаковка занимает 3 секунды.

## Правила безопасности (не ослаблять)

* Удаляются только свои файлы, поимённо (`app`, `runtime`, `T2 Sales Native.exe`, ярлыки, ключи реестра). Никакого рекурсивного удаления папки установки.
* Папка с чужим содержимым (не пустая и без `T2 Sales Native.exe`) отклоняется.
* Пути из архива проверяются: выход за пределы папки установки запрещён.
* Права администратора не запрашиваются (`asInvoker`).

## Правка и проверка

Быстрая сборка только заглушки для просмотра: `setup/build-stub.sh <куда.exe>`, затем `<куда.exe> /demo`. Язык — C# 5: нет интерполяции строк `$""`, `?.`, выражений-членов; менять на более новый нельзя, пока сборка идёт штатным `csc`.
