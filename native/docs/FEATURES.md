# Возможности нативного приложения

[Каталог документации](../../docs/README.md) · [Нативное приложение](../README.md)

## Что добавлено сверх веба

Этого в веб-версии нет или оно устроено иначе.

| Возможность | Где | Что делает |
| --- | --- | --- |
| Сплэш при запуске | `boot/BootSequence.kt`, `boot/SplashScreen.kt` | Небольшое окно проверяет соединение, ищет и сразу ставит обновление, проверяет сессию; затем клиент открывается плавно. Проблемы с обновлением запуск не блокируют |
| Обновление при запуске | `update/*`, установщик с ключом `/UPDATE` | Как в Discord: без клика и без страницы приветствия. Схему безопасности см. в [UPDATES.md](UPDATES.md) |
| Палитра команд (Ctrl+K) | `shell/CommandPalette.kt` | Поиск по экранам, инструментам, действиям; для менеджеров и администраторов — «Продажа: ФИО». Стрелки, Enter, Esc |
| Сочетания клавиш | `Main.kt` | Ctrl+K — палитра, Ctrl+N — «Добавить продажу» (пока окно приложения в фокусе; системного хоткея нет) |
| Живой Heatmap | `analytics/HeatmapScreen.kt` | Каскад ячеек, плавное перетекание цвета и чисел, самообновление раз в 30 с, деталь часа при наведении («13:00 · 5 · 12% от дня · #4 из 13»), пульсация лучшего часа, отметка текущего часа МСК |
| Анимации интерфейса | `components/Motion.kt` и места применения | Переход между экранами, каскад блоков, отсчёт чисел, заполнение полосок, скелетоны вместо спиннера, отклик кнопок и пунктов меню. Описание — в [ARCHITECTURE.md](ARCHITECTURE.md#оформление-и-анимации) |
| Единые выпадающие списки | `components/Dropdowns.kt` | Вместо стандартного меню Material: по ширине поля, со скруглением и тенью, шеврон, галочка на выбранном. Подключены везде, где раньше было стандартное меню: «Добавить продажу», выбор в «Команде», смена в графике, поля `SelectField`, панель сети |
| Сеть DIRECT/RELAY | `network/*`, `shell/NetworkIndicator.kt` | Автопереключение на ретранслятор, ручной выбор режима, диагностика DNS/TCP/TLS/HTTP; как в Electron |
| Установщик в стиле приложения | `../installer/` | Экран как у входа, анимации, живые фразы («Считываем графики смен…»), установка на пользователя без администратора |
| Значок приложения | `desktopApp/icons/icon.ico`, `resources/icon.png` | Логотип T2 у окна, ярлыков и установщика |

## Намеренные отличия от веба

- **Heatmap** обновляется сам раз в 30 секунд; в вебе страница статична. Отключается одной строкой (цикл `while (true)` в `HeatmapScreen.kt`).
- **Обновление** ставится при запуске без клика; в Electron установка идёт только по нажатию.
- **Чат** использует WebSocket с запасным опросом, как веб; отдельных возможностей не добавлено.
- **Отрицательные значения** в Heatmap (корректировки, например −2) закрашены самым бледным оттенком (как пустой час), а число показывается как есть.
- **Стрелки и Enter в выпадающих списках** пока не поддерживаются, только мышь (в палитре команд клавиатура работает).

## Что проверено

Использованы формулировки из [правил оформления](../../docs/DOCUMENTATION-STYLE.md#статусы-и-источники-фактов).

| Что | Статус |
| --- | --- |
| Все вкладки: открываются и показывают реальные данные | Проверено на Windows, ручной прогон по снимкам окна на этапе переноса |
| Сеть DIRECT/RELAY, обновление, установщик (установка, обновление поверх, удаление) | Проверено на Windows на этапе разработки; для обновления — по частям, см. ниже |
| Палитра команд: Ctrl+K, поиск, ↑↓, Enter, Esc; Ctrl+N | Проверено на Windows по снимкам окна |
| Heatmap: каскад, подсветка часа, деталь при наведении | Проверено на Windows по снимкам окна |
| Выпадающие списки: «Добавить продажу» (точка) и панель сети | Проверено на Windows по снимкам окна |
| Выпадающие списки в «Сети», «Команде» и графике | Собирается; глазами не открывались |
| Сплэш: все этапы | Проверено на Windows в демо-режиме `T2_BOOT_DEMO=update` и в обычном запуске |
| Установщик `/UPDATE` | Проверено на Windows в демо-режиме установщика (`/demo /demo-update /UPDATE`) |
| Тесты обновлений (манифест, загрузка, подпись, запуск, скрипт публикации) | Тесты `desktopApp/src/test/.../UpdaterTest.kt` проходят |
| Реальное обновление с сервера на новую версию целиком | Не проверялось |
| Автоматические тесты интерфейса | Нет |
